# Student Portfolio Platform

A responsive personal portfolio website developed to showcase a Computer Science student's journey, including his technical skills, academic projects and experience with software development.

## About the Project

The Student Portfolio Platform is a static web application designed to provide a professional online representation of one's academic and technical work.

The platform brings together information about one's background, technical skills, projects and contact details in one accessible interface.

The main goal of the project is to demonstrate how the skills I have developed throughout my Computer Science studies can be applied to create a functional, responsive and user-friendly web platform.

## Features

- Responsive portfolio layout for desktop, tablet and mobile devices
- Professional hero and personal introduction section
- About Me section describing one's academic and technical journey
- Skills section organised by technology category
- Projects section showcasing academic and personal projects
- Project filtering by category
- Contact section with a structured contact form
- Interactive navigation between portfolio sections
- Responsive design for different screen sizes
- Clean and accessible user interface
